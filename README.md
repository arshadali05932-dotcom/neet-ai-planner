# NEET AI Planner — Personal Edition

A personal NEET preparation planner, designed with a tablet-first responsive layout (especially landscape on Xiaomi Pad 6), while remaining usable on phones and desktops.

## Current starter build
- Responsive dashboard and daily planner
- Add tasks by date, subject and task type
- Mark tasks complete and view a simple progress snapshot
- Saves planner tasks in the current browser using localStorage
- Shows the six planned subject lecture totals (655 overall) as catalogue placeholders

## Important current limitations
- The 655 lecture catalogue has **not** been imported yet; the subject counts are planning totals only.
- Backlog auto-rescheduling, weekly/monthly timetable, revision cycles, tests, data export/import and cross-device sync are not implemented yet.
- Data currently stays in this browser/device. Clearing browser site data can erase it. Use the same browser profile to retain it.
- Do not add API keys, passwords or other secrets to this public repository.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
In the repository, open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select **main** and **/(root)**, then Save. Wait for the published URL to appear on the Pages settings screen.
